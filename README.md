# Link Medi (MOA)

작업 영상 자세·각도(ROM) 분석 + 자가설문 → 병원 연계 참고용 웹앱.

- 참고용이며 진단이 아닙니다. 병원 데이터는 시뮬레이션입니다.
- 원본 영상은 서버로 전송되지 않습니다.
- 구조·수정 가이드: [AGENTS.md](AGENTS.md)

## 실행
`python -m http.server 8000` → http://localhost:8000
